SKVOZ доставляет двунаправленные байтовые потоки между приложениями через NATS.
Универсальное ядро сохраняет порядок байтов, управляет кредитом, состояниями
потоков и ограниченными очередями. Приложения связывают эти потоки с внешним I/O.

Этот репозиторий содержит общую документацию и исходные изображения проекта.
Реализация, сборка, тесты и руководства компонентов принадлежат их репозиториям.

Готовые образы Server и Client Service публикуются в GHCR, настольный клиент
для Ubuntu — как DEB, Android-клиент — как подписанный APK в GitHub Releases.
Core и Network выпускают библиотеки и SDK для сборки зависимых компонентов.
Ссылки на артефакты и порядок обновления зависимостей находятся в
[поставке и совместимости](docs/compatibility.md#готовые-артефакты).
